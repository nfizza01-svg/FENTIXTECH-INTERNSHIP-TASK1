## 📌 Project Overview

The goal of this task was to understand the **basic structure of a webpage** by designing a wireframe layout.

The layout includes:

* 🔝 Header
* 📑 Navigation Menu
* 📦 Content Sections (Left, Main, Right)
* 🔚 Footer

This project helps in understanding how web pages are structured before applying advanced styling.

---

## 🚀 Features

* Simple and clean wireframe layout
* Table-based structure
* Beginner-friendly HTML code
* Clearly divided webpage sections
